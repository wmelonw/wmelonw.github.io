1. 적용 범위와 운영 형태

이 방침은 OpenClaw Manager Reader의 읽기 전용 데스크톱 도구와 이 안내 웹사이트에 적용됩니다. 현재 초대된 테스트 사용자를 위한 개인 운영 도구이며, 일반 공개 가입은 제공하지 않습니다.

이 버전은 사용자 컴퓨터에서 Google Calendar를 조회합니다. 별도로 운영되는 다른 앱이나 기존 매니저 연결에 이 방침이 자동으로 적용되지는 않습니다. AI 요약 또는 메신저 발송을 새로 통합할 때에는 데이터 흐름과 방침을 먼저 갱신하고 필요한 동의를 받습니다.

2. 접근하는 정보

  • 캘린더 목록: 접근 가능한 캘린더의 이름과 식별자. 목록 확인과 캘린더 선택에 사용합니다.
  • 선택한 기간의 일정: 제목, 시작·종료 날짜와 시각, 시간대, 종일/취소 등 조회에 필요한 상태, 장소, 설명, 일정 및 온라인 회의 링크. 반복 일정을 해당 기간의 개별 일정으로 조회할 수 있습니다.
  • 인증 정보: Google이 발급한 접근 토큰·갱신 토큰, 만료 시각, 승인 범위와 OAuth 클라이언트 설정. 연결 유지와 토큰 갱신에 사용합니다. Google 비밀번호는 도구가 수집하지 않습니다.

일정 제목·장소·설명에는 사용자가 입력한 개인 정보가 포함될 수 있습니다. 조회 요청에는 출력에 필요한 필드만 지정하며 참석자 목록이나 주최자 연락처를 별도 필드로 요청하지 않습니다.

요청 권한은 calendar.events.readonly와 calendar.calendarlist.readonly입니다. Google에 승인한 읽기 권한은 사용자가 접근할 수 있는 모든 캘린더에 적용되며, 앱 내 캘린더 선택은 조회 범위를 정하는 기능입니다.

3. 이용 목적과 공유

Google Calendar 데이터는 사용자가 요청한 일정 조회, 과거 기록 확인, 캘린더별 선택과 연결 점검 기능을 제공하는 데 사용합니다. 일정 생성·수정·삭제, 공유 권한 변경에는 사용하지 않습니다.

이 버전의 도구는 Google API와 통신하고 결과를 로컬 명령줄에 표시합니다. 도구 자체가 Calendar 데이터나 토큰을 AI 사업자, Telegram, 광고 사업자 또는 운영자의 별도 서버로 자동 전송하지 않습니다. 사용자가 출력 결과를 다른 도구에 붙여 넣거나 별도로 저장·공유하면 그 행위에는 해당 도구의 처리 방식도 적용됩니다.

운영자는 Calendar 데이터를 판매하거나 광고·신용평가·범용 AI 모델 학습에 사용하지 않습니다. 사람이 데이터를 열람하는 것은 사용자 본인의 사용, 사용자가 구체적으로 동의한 지원, 보안 문제 조사 또는 법적 의무 이행에 필요한 경우로 제한합니다. 지원 문의에는 필요 없는 일정 내용이나 인증 토큰을 보내지 마세요.

4. 보관 기간과 삭제

인증 정보: 사용자 컴퓨터의 전용 인증 폴더에 저장하며, 토큰 갱신 시 최신 정보로 교체합니다. 사용자가 로컬 인증 파일을 삭제하거나 연결을 정리할 때까지 보관합니다. 앱이 파일을 자동 삭제하는 만료 정책은 없습니다.

일정 내용: 기본 조회는 메모리에서 처리하고 명령줄로 출력하며, 도구 자체의 일정 데이터베이스나 영구 일정 캐시를 만들지 않습니다. 터미널 기록, 사용자가 파일로 저장한 출력, 별도 실행 도구의 로그·백업에 남은 사본은 해당 위치에서 직접 삭제해야 합니다. 연결 해제만으로 이런 사본이 삭제되지는 않습니다.

점검 기록: 운영자가 검증 목적으로 저장할 수 있는 조회 건수·성공 여부 등의 점검 결과는 필요가 끝나면 삭제합니다. 지원 이메일을 보내면 문의 처리에 필요한 내용이 이메일 계정에 남을 수 있으며, 삭제를 요청할 수 있습니다. 법적 보관 의무가 있는 경우에는 해당 범위가 우선합니다.

  1. Google 계정의 서드 파티 연결 관리에서 OpenClaw Manager Reader를 선택하고 접근을 철회합니다. 이후 API 조회나 갱신은 사용할 수 없습니다.

  3. 저장한 조회 결과·터미널 기록·백업은 해당 도구에서 삭제합니다. 운영자에게 제공한 지원 자료의 열람·정정·삭제는 아래 문의 주소로 요청할 수 있습니다.

이 앱은 읽기 전용이므로 Google Calendar 원본 일정을 변경하거나 삭제할 수 없습니다. 원본의 정정·삭제는 Google Calendar에서 직접 처리합니다.

6. 보호 조치

Google과의 인증·API 통신에는 HTTPS를 사용합니다. 데스크톱 OAuth의 승인 응답은 인증 중 잠시 열린 로컬 루프백 주소로 전달되며, PKCE를 사용합니다. 승인 범위를 검사해 요청한 두 읽기 권한과 다르면 연결을 저장하거나 사용하지 않습니다.

인증 폴더와 파일은 소유자만 접근하도록 운영체제 권한을 제한하고, 공개 웹사이트나 소스 저장소에 인증 파일을 포함하지 않습니다. 인증 파일에는 별도 애플리케이션 암호화를 적용하지 않으므로 기기의 계정·디스크 보안도 필요합니다. 보안을 절대적으로 보장한다고 주장하지 않습니다.

English summary

OpenClaw Manager Reader is operated by Daehyun Kim (wmelonw). It is a personal desktop application currently limited to invited test users. It reads Calendar names/IDs and selected event fields to display local agendas and past records. It requests only calendar.events.readonly and calendar.calendarlist.readonly.

OAuth tokens are stored locally with owner-only file permissions until removed. The app does not create an event database; terminal output, user exports and backups may remain until deleted by their owner. It does not automatically send Calendar data to AI providers, Telegram, advertising services or a developer backend. Data is not sold, used for advertising, credit decisions or general-purpose AI training. Any human access is limited to user use, specific consent for support, security purposes or legal obligations.

Users can revoke access in their Google Account and delete local credentials and saved output. This informational website does not receive Calendar data or OAuth tokens.
