OpenClaw Manager Reader는 Google Calendar의 일정과 캘린더 목록을 조회하는 개인용 데스크톱 도구입니다. 선택한 기간의 일정을 로컬 명령줄에서 확인합니다.

할 수 있는 일

다가오는 일정 확인

하루 또는 여러 날의 일정 제목, 시작·종료 시각, 장소, 설명과 일정 링크를 확인합니다. 종일 일정과 반복 일정도 조회할 수 있습니다.

지난 기록과 캘린더별 조회

캘린더 이름을 선택해 지난 기록을 찾거나, 여러 캘린더의 일정을 함께 확인합니다. 개인 루틴을 점검할 때 필요한 기록 조회에 사용할 수 있습니다.

연결 상태 확인

일정 내용을 출력하지 않고 조회한 캘린더 수와 일정 수만 확인하는 점검 기능을 제공합니다.

캘린더 목록 읽기

calendar.calendarlist.readonly

접근 가능한 캘린더 이름을 확인하고, 조회할 캘린더를 선택하기 위해 사용합니다.

일정 읽기

calendar.events.readonly

일정의 시각·제목·장소·설명을 보여주기 위해 사용합니다. 빈 시간 정보만으로는 이 내용을 제공할 수 없습니다.

Google의 읽기 권한은 접근 가능한 모든 캘린더에 적용됩니다. 도구에서 특정 캘린더를 선택해도 Google에 승인한 권한 자체가 그 캘린더 하나로 줄어들지는 않습니다.

사용 흐름

  1. Google에서 직접 승인
    Google 동의 화면에서 앱 이름과 두 읽기 권한을 확인합니다. Google 비밀번호를 이 도구에 입력하지 않습니다.
  2. 로컬에서 기간·캘린더 선택
    운영자가 제공하는 명령줄 도구로 조회합니다. 결과는 사용자 컴퓨터에 표시됩니다.
  3. 언제든 연결 해제
    Google 계정의 연결 관리에서 접근을 철회할 수 있습니다. 저장된 인증 파일과 별도로 저장한 결과도 삭제할 수 있습니다.

데이터를 다루는 방식

이 버전은 Google API에서 받은 정보를 로컬에서 조회합니다. 일정 생성·수정·삭제, 캘린더 공유 설정 변경 기능은 없습니다. AI 서비스 호출이나 텔레그램 자동 발송 기능도 포함하지 않습니다.

이 웹사이트는 기능과 정책을 안내하는 정적 페이지입니다. 웹사이트에서 Google 로그인이나 캘린더 연결을 요청하지 않으며, 일정이나 인증 토큰을 받지 않습니다.

About this application

OpenClaw Manager Reader is a personal, local desktop tool for viewing Google Calendar lists and events. It uses only read-only Calendar scopes, displays selected date ranges locally, and does not edit events. This website provides product and privacy information; it does not collect Calendar data or OAuth tokens. Access is currently limited to invited test users.
